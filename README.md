# Mobile-Data-Acquisition-Project
Mobile Data Acquisition (DAQ) System designed for aeroderivative gas turbine test cells. Developed a standalone, modular platform for real-time engine performance monitoring using Keyence instrumentation, pressure transmitters, and thermocouple inputs.
## Overview

This project involved the design, development, and deployment of a mobile Data Acquisition (DAQ) system used to collect real-time performance data from aeroderivative gas turbines during test cell operations. The system was developed during my Design Engineering Internship at PROENERGY to address the challenge of acquiring high-fidelity engine data without introducing any interference to test cell control systems.

The final solution is a standalone, mobile DAQ platform that integrates instrumentation hardware, sensor interfaces, and data acquisition software into a single portable unit. The system enables engineers to monitor and record critical engine parameters while maintaining complete isolation from operational control systems.

Problem Statement

Performance and operational data collected during gas turbine test runs is critical for validating engine health before shipment to customers. However, direct sensor placement within the engine is often impractical due to extreme temperatures and harsh operating environments. Additionally, any data collection system must operate independently of the test cell controls to eliminate the possibility of affecting engine operation.

Solution

I designed and built a modular mobile DAQ cart from concept through implementation. The project included:

Generating and evaluating multiple design concepts
Developing CAD models using 80/20 Design Software
Selecting and procuring hardware components
Designing a modular aluminum-extrusion framework
Integrating instrumentation hardware and sensor interfaces
Planning and implementing organized wiring layouts
Assembling and validating the complete system
Developing a read-only data acquisition architecture to ensure non-intrusive operation
System Features
Modular 80/20 aluminum-extrusion frame
NEMA 4 weather-resistant enclosure
Dedicated AC enclosure for environmental control
Keyence sensor interface system
Marlin connector integration
Pressure measurement instrumentation
Thermocouple connectivity using K-type and U-type connectors
Organized wiring and cable management architecture
Real-time data collection and recording
Independent, read-only operation to prevent interference with test cell control systems

Project Outcome

The project successfully delivered a fully functional mobile DAQ unit capable of supporting gas turbine test cell operations while maintaining complete isolation from engine control systems. The system provides a practical platform for collecting and analyzing performance data, improving engineers' ability to validate turbine operation and support downstream analysis workflows.
